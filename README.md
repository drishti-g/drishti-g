### 🚀 Featured projects

#### 📝 [AI Meeting Action Item Extractor](https://github.com/drishti-g/AI-Meeting-action-item-extractor)
An LLM-powered multi-stage verification pipeline that converts unstructured meeting transcripts into structured, actionable tasks with responsible owners, deadlines, and confidence scores.

- Multi-stage pipeline: transcript cleaning → LLM extraction → rule-based validation → LLM verification pass
- Strict structured output via Pydantic schemas (task, owner, deadline, status, and confidence score)
- Dual verification mechanism (deterministic rule validation + secondary LLM reflection) to eliminate hallucinations and ungrounded task assignments
- Real-time interactive UI for transcript uploads, structured reviews, and task export
- Deployed: Streamlit on Community Cloud ([Live Demo](https://aimeetingactionitemextractor.streamlit.app/))
